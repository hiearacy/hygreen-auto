# 향그린 예약 자동입력 (Hygreen Auto)

Windows PC에서 **NOL 알림(야놀자·아고다 등)과 여기어때** 예약문자를 인식해 기존 엑셀의 **`데이터`** 시트에 입력하는 프로그램입니다. 실제 고객의 예약자료는 GitHub에 저장하지 않습니다.

## 현재 지원 범위 (안전한 첫 버전)

- 카카오톡에서 **사용자가 복사한 알림을 붙여넣기** → 예약 분석 → 엑셀 기록
- 여러 알림을 복사하거나 카카오톡 대화 복사 파일(`.txt`)을 가져와 일괄 처리
- **수신 폴더 자동입력**: 별도 알림 전달 도구가 텍스트 파일을 만드는 경우 10초 간격 확인 후 자동 기록. 폴더 선택과 사용자 활성화가 필요하며 기본값은 OFF.
- 예약번호 중복 검사, 기존 예약 취소 처리, 파일 백업, 원본 시트 구조 유지
- 실제 공급처가 아고다인 경우도 기존 엑셀 `예약경로`는 `야놀자`로 기록하고 프로그램 로그에는 `아고다`로 표시 (기존 사용방식 유지).
- **카카오톡 PC 창을 직접 몰래 읽거나 제어하지 않습니다.** 백그라운드의 카카오톡 메시지를 자동 수집하려면 별도 안정적인 알림 전달 연결이 필요합니다. 본 버전만 실행하면 카카오톡 메시지가 저절로 들어오지는 않습니다.

## 처음 실행

1. Windows 10/11, **Microsoft Excel 데스크톱 앱**, Python 3.11+ 설치
2. 이 저장소 다운로드 후 `install_windows.bat` 더블클릭 (필요 패키지 설치)
3. `start_windows.bat` 더블클릭
4. 기존 `예약자명단(1).xlsx`처럼 `데이터` 시트가 있는 **작업용 복사본 엑셀** 선택
5. 카카오톡 `NOL 알림` 또는 `여기어때` 예약 알림 전체 복사 → 프로그램에 붙여넣기 → **예약 분석** → **엑셀 기록**
6. 결과와 원본 백업(`향그린_자동백업` 폴더) 확인 후 실제 영업일보에 적용

### 자동 수신 폴더 사용

예약 메시지 하나 또는 카카오톡 대화 복사 텍스트를 **UTF-8 `.txt`**로 저장하도록 다른 도구를 설정하고, 프로그램에서 해당 폴더를 선택한 뒤 `자동 입력 켜기`를 선택하세요. 파일 내용이 바뀌면 다시 검사합니다. 별도 전달 도구가 없는 상태에서는 **수동 붙여넣기**로 사용합니다.

## 엑셀 열 대응

|열|입력값|
|---|---|
|A|입실일 (Excel 날짜 형식 — `합계` 시트 계산 반영)|
|B|예약번호 (문자열)|
|C|예약경로 (`야놀자` / `여기`)|
|D|예약자명|
|E|차량 1, 도보 0, 미확인 시 공란|
|H|객실 종류|
|I|금액|
|M|연락처 (문자열)|

입실 날짜를 문자열로 입력하던 기존 버전의 문제를 해결합니다. 금액, 객실타입, 날짜 또는 예약자명이 없을 때는 자동기록하지 않고 확인을 요청합니다. 이미 기록된 예약은 중복 입력하지 않습니다. 취소 알림은 동일 예약번호가 기록된 기존 행의 객실/금액/차량을 비우고 `L`열에 `예약취소`를 적습니다. **기존 행을 찾을 수 없는 취소는 별도로 수동 확인이 필요합니다.**

## 주의사항

- 실제 컴퓨터의 카카오톡과 Excel COM 연동은 이 환경에서 실행 검증할 수 없었습니다. **복사본으로 테스트한 뒤** 원본에 사용하세요.
- 자동 입력 중 Excel에 저장하지 않은 수동 수정이 있으면 안전을 위해 기록을 중지합니다. 먼저 엑셀을 저장하세요.
- 파일 원본 백업은 같은 디렉터리의 `향그린_자동백업`에 최대 30개까지 보관합니다.
- 이 프로그램은 Excel COM만 사용하며 바탕화면/마우스/키보드/전체 화면을 제어하지 않습니다.
- 개인정보가 들어간 엑셀, 카카오 대화 텍스트, 설정파일을 **공개 GitHub 저장소에 올리지 마세요.**

## Python 설치 없이 Windows에서 실행하기 (EXE)

GitHub의 **Actions → Build Windows EXE**에서 `Run workflow`를 실행하고 빌드가 성공하면 해당 실행 페이지의 **Artifacts → HygreenAuto-Windows**를 다운로드하여 압축을 해제한 뒤 `HygreenAuto.exe`를 실행할 수 있습니다. **빌드 성공 여부와 실제 Windows 작동은 별도 확인이 필요합니다.** EXE 파일에도 Microsoft Excel 데스크톱 앱은 필요합니다.
