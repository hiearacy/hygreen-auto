# 향그린 예약 자동입력 v3.2 — PC 카카오톡 화면 감시 (실험적 OCR)

**목적:** Windows PC에 실제로 열어 둔 카카오톡 독립 채팅창 `NOL 알림`, `여기어때`를 읽고 기존 숙박 예약 Excel(`데이터` 시트)에 자동 반영합니다. 기존 v1의 **수동 붙여넣기** 및 폴더 감시 기능도 유지합니다. v2에서 사용하던 **안드로이드·MacroDroid 설정은 이 PC 전용 방식에 필요하지 않습니다.**

> ⚠️ **현재는 테스트용 버전입니다.** Windows 카카오톡의 화면 글자를 OCR로 읽기 때문에 **인식 누락과 오인식 가능성**이 있습니다. 실제 Excel 자동 기록 기능은 사용자가 직접 별도로 켜야 합니다. 코드의 단위 테스트 15개는 통과했지만, 사용자의 실제 Windows/카카오톡 환경에서 **실시간 OCR 인식률이나 무인 자동 기록 성공은 아직 검증하지 않았습니다.**

## 1. Windows PC에서 설치하기

1. **Python 3.11 이상**, **Microsoft Excel 데스크톱 프로그램**, **카카오톡 PC 버전**을 준비합니다.
2. ZIP을 새 폴더에 압축을 풀고 `install_windows.bat` → `start_windows.bat`을 차례로 실행합니다.
   - Windows Smart App Control이 `.bat`를 막으면 폴더에서 **터미널에서 열기**를 선택하여 `py -3 -m pip install -r requirements.txt` 및 `py -3 app.py`로 실행합니다. 보안 기능을 끌 필요는 없습니다.
3. 화면 문자 인식을 위한 **Tesseract OCR**을 별도 설치합니다.
   - 설치 안내: [UB Mannheim의 Tesseract Windows 설치 프로그램](https://github.com/UB-Mannheim/tesseract/wiki)
   - 설치할 때 **Korean (kor)** 와 **English (eng)** 언어팩을 선택합니다.
   - 기본 설치 경로 `C:\Program Files\Tesseract-OCR\tesseract.exe`를 권장합니다. 앱은 이 경로를 자동 확인합니다.
   - 한국어가 설치되어 있는지 터미널에서 `"C:\Program Files\Tesseract-OCR\tesseract.exe" --list-langs`로 확인합니다. `kor`와 `eng`가 있어야 합니다.
4. 프로그램에서 **원본이 아닌 테스트용 엑셀 복사본**을 선택합니다. 엑셀 파일은 자동기록 중 가능하면 닫아 두세요.

## 2. PC 카카오톡 독립 창 준비

1. 카카오톡 PC 버전에서 `NOL 알림`, `여기어때` 채팅방을 **각각 독립 창**으로 꺼냅니다.
2. **제목표시줄이 정확히 `NOL 알림` / `여기어때`인 두 채팅창**을 화면에 놓습니다.
3. 두 채팅창을 가능한 **가로 420px 이상** 넓게 두고, 카카오톡 설정에서 글씨 크기를 적절히 크게 설정해 인식률을 올립니다.
4. **채팅 메시지가 화면에 보이도록** 두고 다른 브라우저·앱으로 가리지 마세요. Windows 화면잠금, 최소화, 원격 세션 분리 시 읽지 못합니다.
5. **`화면 읽기 테스트`**를 누르면 향그린 프로그램 자기 창이 잠시 숨겨진 뒤 두 카카오톡 창을 OCR로 읽고 다시 표시됩니다.
6. OCR로 읽은 글자가 큰 텍스트 칸에 나타나면 예약번호·예약자·날짜·객실·금액이 **원문과 일치하는지** 확인하세요. 글자가 빠진다면 자동기록을 켜지 마세요.
7. **`7초마다 감시`**를 선택합니다. 이때 향그린 프로그램을 최소화하거나 채팅창과 겹치지 않는 위치에 두세요. *카카오톡 채팅창은 최소화하지 마세요.*
8. 실제 수신 문자를 여러 차례 정확하게 읽는지 확인한 뒤, **테스트용 엑셀에서만** `자동 엑셀 기록`을 활성화하세요. 취소 처리도 테스트하세요.
9. Excel 시트의 `데이터`에서 신규 행 및 취소 여부를 확인한 후에만 실제 장부로 전환하세요.

## 3. 안전 및 정확도 제약

- 화면 감시는 `7초마다 감시`를 선택한 경우에만 실행되며, 프로그램 재시작 시 **OFF**입니다.
- 자동 기록은 별도 사용자의 확인 후 **ON**, 재시작 시 기본 **OFF**입니다.
- **마우스 이동·클릭, 키보드 합성, 카카오톡 메모리 읽기, SQL DB 복호화, 창 강제 활성화, 관리자 권한 요청이 없습니다.** 자신의 앱 창만 테스트 동안 잠깐 숨깁니다.
- 이미지 캡처와 OCR은 PC의 메모리에서만 처리하며 스크린샷/인식 결과를 외부로 업로드하지 않습니다. 테스트 미리보기는 앱 안에서만 보여줍니다.
- `KakaoTalk.exe` 프로세스가 가진, 정확히 이름이 일치하는 **두 독립 채팅창**만 검사합니다. 다른 채팅방/개인 대화는 감시하지 않습니다.
- 다른 앱 창이 카카오톡을 크게 가리면 읽기를 건너뜁니다. 화면이 잠기거나 KakaoTalk이 최소화된 상태의 무인 감시는 지원하지 않습니다.
- **확정된 예약번호·입실일·객실·금액·예약자명**이 있을 때만 자동기록 후보로 인정합니다. 새 예약은 두 차례, 취소는 세 차례 연속 동일한 내용으로 인식해야 자동기록합니다.
- 단 **동일하게 잘못 읽는 OCR 오류**도 있을 수 있습니다. 신뢰 가능한 업무 자동화를 위해서는 일정 기간 수동 대조가 필수입니다.
- Excel 기록 전 자동백업, 예약번호 중복확인, 취소 대상 예약번호가 없을 때 오류 중단을 유지합니다.
- GitHub에 고객 예약 실데이터·전화번호·인증키는 절대 커밋하지 마세요.

## 4. Excel 열

`데이터` 시트의 기존 구조를 그대로 사용합니다. A 입실일(진짜 날짜), B 예약번호(문자열), C 예약경로, D 예약자, E 차량 여부, H 객실, I 판매금액, M 전화번호입니다. 이전에 `합계` 시트가 계산되도록 날짜를 문자열 대신 실제 Excel 날짜형으로 기록합니다.

## 5. 파싱 테스트

```powershell
py -3 -m unittest discover -s tests -v
```

이 테스트는 예약문자/서버/화면 인식 **파서**의 로직을 검증하며, 카카오톡 PC 창을 읽는 실제 Windows 화면 OCR 정확도를 보장하지 않습니다.

## 6. 향후 개선

실제 `화면 읽기 테스트`의 OCR 결과가 너무 부정확하면 **카카오톡 대화 내용 내보내기(.txt)**를 이용한 보조 수집이나 Windows 공식 화면 캡처(`Windows.Graphics.Capture`) 기반 창별 캡처로 변경할 수 있습니다. 공식 창 캡처는 가려진 창을 읽는 데 도움이 될 수 있지만, 카카오톡 자체의 구현·Windows 버전과 최소화 상태에서 정상 작동하는지는 별도 검증이 필요합니다.

기존 v2 LAN 수신 서버 소스는 호환성을 위해 남아 있지만, v3 기본 UI에서는 휴대폰 연동을 노출하지 않습니다.
## v3.1 화면에서 채팅방을 찾지 못할 때

- Windows 창 제목이 채팅방 이름과 달라도 카카오톡(`KakaoTalk.exe`) 창을 먼저 찾고, 화면 상단의 `여기어때` 또는 `NOL 알림` 이름을 로컬 OCR로 확인합니다.
- 채팅방은 독립 창으로 열고 **화면에 완전히 보이도록** 놓아주세요. 최소화·화면 잠금·다른 창의 가림은 지원하지 않습니다.
- 프로그램에서 `화면 읽기 테스트`를 먼저 누르고, 텍스트와 예약 분석 결과를 직접 확인하세요.
- `자동 엑셀 기록`은 처음에 끈 채로 사용하세요. 재인식(일반 2회, 취소 3회)은 OCR 오인식을 완전히 방지하지 못합니다.
- 카카오톡 Windows 업데이트로 실행 파일 이름이 바뀌거나 화면 구조가 달라지면 추가 수정이 필요합니다.

## v3.2 채팅창을 찾지 못할 때 (직접 지정)

- v3.1의 '카카오톡 소유의 보이는 창을 찾지 못했습니다' 오류는 `KakaoTalk.exe` 실행 파일 이름을 정확히 요구한 검색 조건 때문일 수 있습니다. 사용자 PC에서 원인은 아직 확인되지 않았습니다.
- v3.2는 이름에 Kakao가 들어가는 프로세스를 폭넓게 인식합니다. 그래도 검색이 실패하면 **채팅창 직접 선택**을 누르세요.
- Windows에 표시 중인 창 목록에서 `NOL 알림`과 `여기어때`를 하나씩 고릅니다. 창의 실행 파일 이름, 위치, 크기로 구분할 수 있습니다.
- 그다음 **화면 읽기 테스트**를 누릅니다. 직접 선택했더라도 창 상단의 실제 채팅방 이름이 OCR로 확인되지 않으면 **엑셀에 쓰지 않습니다.**
- 창을 닫았다 다시 열었으면 다시 지정해 주세요. 자동 엑셀 기록은 정확도 검증 전까지 꺼 두세요.
