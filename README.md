# 향그린 예약 자동입력 v2 — 휴대폰 카카오톡 알림 자동수신

Windows PC에서 NOL(야놀자, 아고다 등) 및 여기어때 예약 알림을 분석해 기존 Excel 파일의 **`데이터`** 시트에 적는 프로그램입니다. 기존 v1의 수동 붙여넣기와 폴더 자동감시도 유지합니다.

> **중요:** v2는 **안드로이드 휴대폰의 MacroDroid**를 이용해 카카오톡 알림을 집 PC로 전달하는 **연결 기능**을 구현한 버전입니다. PC의 카카오톡 화면을 읽거나 제어하지 않습니다. **프로그램만 설치한다고 알림이 자동 수집되지는 않습니다.** 휴대폰 연동이 필요하며, 실제 기기에서 알림 전문이 전달되는지 검증해야 합니다. iOS에서는 이 방식이 그대로 동작하지 않습니다.

## 1. Windows PC 설치·실행

1. Windows 10/11, Microsoft Excel 데스크톱 앱, Python 3.11 이상 설치.
2. ZIP 압축 풀기 → `install_windows.bat` → `start_windows.bat` 순서로 실행.
   - Windows Smart App Control이 `.bat`를 차단하면 폴더에서 터미널을 연 뒤 `py -3 -m pip install -r requirements.txt` 및 `py -3 app.py` 실행. 보호 기능을 끌 필요 없습니다.
3. `파일 선택`에서 실제 장부가 아닌 **작업용 엑셀 복사본**을 선택. Excel 파일은 입력 중 닫아두세요.
4. 기존 수동 복사 → `예약 분석` → `엑셀 기록` 기능이 계속 동작하는지 확인.
5. `LAN 수신 시작` 클릭. Windows 방화벽 질문이 뜨면 **신뢰하는 개인 네트워크에서만 허용**. 공용 네트워크로 연결된 경우 중지.
6. `휴대폰 연결 정보 복사`를 클릭하면 URL, 인증키, 요청 형식이 복사됩니다. **인증키를 타인이나 공개 저장소에 공유하지 마세요.**

## 2. 안드로이드 휴대폰 설정 — MacroDroid

휴대폰과 PC가 **같은 신뢰할 수 있는 Wi-Fi/로컬 네트워크**에 있어야 합니다. 모바일 데이터만 사용 중이면 연결되지 않습니다. PC의 IP는 프로그램의 `수신 대기: 192.168.x.x:8765`에서 확인합니다. `PC의 IPv4 주소 확인 필요`라고 보이면 Windows 터미널에서 `ipconfig`를 실행해 현재 Wi-Fi/이더넷의 IPv4 주소를 사용합니다. 라우터가 기기끼리의 통신을 차단한다면 연결되지 않습니다.

MacroDroid(Android)에서 **아래 설정을 각각 NOL 알림 및 여기어때에 대해 두 개의 매크로로 만들어** 알림을 제한적으로 전달하세요.

- **트리거**: `알림 수신(Notification Received)` → 애플리케이션 **카카오톡**만 선택 → 해당 매크로에서 `NOL 알림` 또는 `여기어때`로 제목/텍스트 조건을 좁힙니다. 가능하면 제목과 정확히 일치하도록 설정합니다. 알림 접근 권한이 필요합니다.
- **동작**: `HTTP Request` → **POST** → `휴대폰 연결 정보 복사`에서 얻은 `http://192.168.x.x:8765/api/v1/notification` 주소.
- **Content-Type**: `text/plain; charset=utf-8`.
- **Header**: `X-Hygreen-Token` = 프로그램에서 복사한 **비밀키** (URL 뒤에 붙이지 않음).
- **본문(Body)**: 다음 세 줄을 **Magic Text 삽입 기능**으로 작성합니다. 휴대폰 버전에 따라 표시 이름이 다를 수 있습니다.

```text
{not_title}
{notification}
{not_text_big}
```

위 세 항목이 작동하는지 MacroDroid 테스트 알림으로 먼저 확인하세요. `{not_text_big}`이 지원되지 않는 경우 매크로의 Magic Text 선택 메뉴에서 `Notification big text / Extended notification text`를 찾거나, 그 줄을 빼고 보내세요. 서버는 첫 줄이 **`NOL 알림` / `여기어때`**인 알림만 수신합니다. 다른 개인 대화는 보내지 않도록 트리거를 반드시 제한하세요.

1. PC에서 `LAN 수신 시작`을 켜되, **`자동 엑셀 기록` 체크는 끄고** 처음 알림을 수신합니다.
2. `카카오 알림 수신됨 · 자동 기록 OFF`라는 로그가 뜨면 전송 성공입니다. 저장 위치는 **`%LOCALAPPDATA%\\HygreenAuto\\lan_inbox`**입니다.
3. 이 폴더의 수신 텍스트에 **예약번호, 객실, 판매금액, 예약자, 입실일이 전부 들어 있는지** 확인합니다. 알림이 잘려 있다면 엑셀 자동 기록을 켜지 마세요.
4. 테스트용 엑셀을 선택하고 `자동 엑셀 기록 (테스트 후 켜기)`를 체크. 수신함의 기존 알림부터 자동 처리합니다.
5. `수신함`에 처리 성공 알림은 삭제되고, **인식 실패나 취소 대상 예약번호 미발견** 등은 `%LOCALAPPDATA%\\HygreenAuto\\review_needed`에 보관됩니다. 오류 로그를 확인해 수동 조치하세요.
6. 여러 건을 확인한 뒤에만 실사용 엑셀 파일로 전환하세요.

**정상 HTTP 응답은 `202 received; pending validation`**입니다. 이는 알림이 PC에 *접수*됐다는 뜻이며, **Excel 기록 성공과는 다릅니다**. 실제 성공 여부는 프로그램 하단 로그와 엑셀에서 확인하세요.

## 3. 구현된 안전장치

- 카카오톡 PC나 바탕화면을 클릭, 키 입력, 화면 캡처하지 않음.
- 네트워크 수신은 **사용자가 `LAN 수신 시작`을 누른 동안만 활성화**. 프로그램 재시작 시 기본 **OFF**.
- 자동 Excel 기록은 **별도의 체크박스를 켜야 시작**. 프로그램 재시작 시 기본 **OFF**.
- 수신 서버는 로컬 IPv4 네트워크(127/10/172.16~31/192.168) 주소만 허용. 공개 인터넷에 포트를 포워딩하지 마세요.
- 길고 무작위인 개인 인증키를 `X-Hygreen-Token` 헤더에서 대조. 설정파일 `%LOCALAPPDATA%\\HygreenAuto\\settings.json`에만 저장.
- 인증되지 않았거나 첫 줄 발신자명이 다른 알림은 차단. 수신 내용 크기는 16KiB로 제한.
- 엑셀 기록 전에 예약번호·예약자·날짜·객실·금액을 검증. 정보가 불완전하면 자동 기록하지 않고 **수동 확인 폴더**로 이동.
- 동일 예약번호 중복 입력 방지, 취소는 동일 예약번호를 찾아 처리. 매번 데이터 변경 전 기존 Excel 자동백업 수행.
- Excel 작업 성공 시 수신 텍스트를 삭제. 실패 시 수동 검토를 위해 로컬 `review_needed`에 남김.
- **외부 클라우드 서버로 예약문자를 보내지 않음**. 다만 안드로이드↔PC 간 연결은 **LAN HTTP(암호화되지 않은 전송)**이므로 반드시 신뢰하는 개인 Wi-Fi에서만 쓰고, 외부 네트워크로 포트 공개하지 마세요.
- GitHub(공개 저장소)에는 **코드만 업로드**. 고객 이름, 연락처, 예약기록 또는 인증키는 절대 커밋하지 마세요.

## 4. 예약 엑셀 입력 형식

| 열 | 내용 |
|---|---|
| A | 입실일: 실제 Excel 날짜 타입 (`합계` 시트 집계용) |
| B | 예약번호: 텍스트로 보관 |
| C | 야놀자 / 여기 (아고다 예약도 기존 방식대로 야놀자) |
| D | 예약자명 |
| E | 차량 1 / 도보 0 / 미확인 공란 |
| H | 객실종류 |
| I | 결제금액 |
| M | 연락처: 텍스트 |

취소 메시지는 예약번호에 해당하는 기존 행을 찾아 객실·금액·차량 내용을 비우고, 비고에 `예약취소`를 기록합니다. **취소 대상이 존재하지 않으면 자동 성공으로 처리하지 않습니다.**

## 5. 테스트

Windows 외 환경에서도 파싱 및 로컬 HTTP 수신 테스트 가능:

```powershell
py -3 -m unittest discover -s tests -v
```

Windows Excel COM 기록 및 안드로이드 MacroDroid/카카오톡 실제 알림 연동은 사용자 PC·휴대폰에서 테스트해야 합니다. 특히 **Android 알림에 예약 내용 전체가 표시되는지**가 핵심 검증 항목입니다.
